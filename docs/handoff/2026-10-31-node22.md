## Rollback
Image Node 20 cũ **không còn** trong content store (không tag/commit được để giữ lại).
Rollback = build lại Dockerfile Node 20:
```bash
cd /opt/chess && cp Dockerfile.bak-20261031-node20 Dockerfile && docker compose up -d --build
git checkout Dockerfile   # sau khi xong, trả Dockerfile về đúng git
```

## Cập nhật 31/10 — quy trình deploy giữ image rollback (Ops)
Từ nay deploy bằng script (không gõ tay `docker compose up --build`):
```bash
cd /opt/chess && bash scripts/deploy-server.sh
```
Script: tag `chess-chess:latest` → `chess-chess:rollback` trước khi build → `git pull` → `docker compose build chess`
→ `docker compose up -d --no-build chess` → chờ `/healthz` 200. Chỉ giữ **1** tag rollback (bản ngay trước);
image rollback cũ bị mất tag sẽ được xoá để không đầy đĩa mcp-80.

Rollback (không build lại, gần như không downtime):
```bash
cd /opt/chess && bash scripts/rollback-server.sh
# = docker tag chess-chess:rollback chess-chess:latest; docker compose up -d --no-build chess
```
`push.ps1` chỉ push git từ máy dev nên không gắn bước này vào đó.
